📋 Comandos Disponibles

# Comandos CLI Directos node local-indexer.js --index # Indexar codebase completo node local-indexer.js --clear # Limpiar índice completo node local-indexer.js --clear --index # Limpiar y reindexar # Comandos desde el Dashboard POST /api/command { "command": "index" # Indexar codebase "command": "clear" # Limpiar índice "command": "clear-and-index" # Limpiar y reindexar "command": "stats" # Ver estadísticas "command": "health" # Verificar salud }

🌐 API Endpoints

# Endpoints principales GET /api # Información del API GET /api/health # Estado del servidor GET /api/stats # Estadísticas del proyecto POST /api/command # Ejecutar comandos POST /api/search/similar # Buscar código similar POST /api/analyze/complexity # Analizar complejidad POST /api/index/codebase # Indexar codebase POST /api/index/file # Indexar archivo individual

🚀 Ejemplos de Uso

Desde la Terminal

$ cd code-analysis $ node local-indexer.js --index ✅ Base de datos conectada 🚀 Iniciando indexación del codebase... 📁 Directorio base: ../ 📊 Encontrados 179 archivos para indexar ✅ Archivos indexados: 179 📊 Total de palabras indexadas: 248697

Desde el Dashboard

# Abrir en navegador http://localhost:3001/api code-analysis/indexer-dashboard.html # Interacción visual con: - Botones de comandos - Campo de búsqueda - Estadísticas en tiempo real - Resultados interactivos

Desde API

# Buscar código similar curl -X POST http://localhost:3001/api/search/similar \ -H "Content-Type: application/json" \ -d '{"query": "function indexFile"}' # Obtener estadísticas curl http://localhost:3001/api/stats # Ejecutar comandos curl -X POST http://localhost:3001/api/command \ -H "Content-Type: application/json" \ -d '{"command": "stats"}'

🔧 Integración con VS Code

# Configuración en settings.json { "codeAnalysis.apiUrl": "http://localhost:3001/api", "codeAnalysis.enableAutoAnalysis": true } # Funcionalidades disponibles: - Búsqueda de código desde el editor - Análisis de complejidad en tiempo real - Sugerencias de refactorización - Navegación inteligente entre archivos

❓ Preguntas Frecuentes

¿Cómo sé si el servidor está activo?

Verifica el indicador de estado en la esquina superior derecha del dashboard o visita http://localhost:3001/api

¿Qué archivos se indexan automáticamente?

JavaScript, JSON, HTML, CSS, SQL, Markdown y más. Se excluyen node_modules, .git, logs y carpetas de exclusión.

¿Puedo usar esto en otros proyectos?

Sí, simplemente cambia el directorio base en los comandos o configura el dashboard para apuntar a otra ruta.

¿Cómo integro esto con mi flujo de trabajo?

Usa el script start-dashboard.bat para iniciar todo automáticamente o integra los endpoints API en tus scripts de desarrollo.
