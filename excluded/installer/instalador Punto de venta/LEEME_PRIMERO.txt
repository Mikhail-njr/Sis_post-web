1. 📋 DESCRIPCIÓN GENERAL
================================================================================

Este instalador configura completamente el Sistema POS (Punto de Venta) incluyendo:

✅ COMPONENTES PRINCIPALES:
   • Node.js (Entorno de ejecución JavaScript)
   • ngrok (Acceso remoto seguro)
   • Aplicación Electron (Interfaz nativa)
   • Base de datos SQLite
   • Dependencias y librerías

✅ CARACTERÍSTICAS:
   • Instalación automática guiada
   • Verificación de requisitos
   • Configuración completa
   • Datos de ejemplo incluidos
   • Utilidades de respaldo y restauración

✅ MODO DE USO:
   • Aplicación de escritorio independiente
   • Sin necesidad de navegador web
   • Funciona con o sin conexión a internet

2. 🔧 REQUISITOS DEL SISTEMA
================================================================================

MÍNIMOS:
• Sistema Operativo: Windows 7 SP1 o superior
• Procesador: 1 GHz o superior

3. ⚡ INSTALACIÓN RÁPIDA
================================================================================

PASO 1: Asegúrese de tener ambos archivos:
       • instalar.bat (este instalador)
       • sistema-pos-electron.zip (paquete comprimido)

PASO 2: Haga doble clic en "instalar.bat"
PASO 3: El instalador descomprimirá automáticamente el sistema
PASO 4: Seleccione "Instalación Completa"
PASO 5: Espere a que se complete la instalación
PASO 6: Use el acceso directo en el escritorio

¡LISTO! El sistema estará funcionando en menos de 10 minutos.

================================================================================

7. 🆘 SOLUCIÓN DE PROBLEMAS
================================================================================

PROBLEMA: "Node.js no encontrado"
SOLUCIÓN:
• Ejecute: instaladores\instalar_nodejs.bat
• O descargue manualmente desde nodejs.org

PROBLEMA: "ngrok no configurado"
SOLUCIÓN:
• Regístrese en ngrok.com
• Obtenga su Auth Token
• Ejecute: instaladores\configurar_ngrok.bat

PROBLEMA: "Puerto 3000 ocupado"
SOLUCIÓN:
• Cierre otras aplicaciones
• O configure un puerto diferente en la aplicación

PROBLEMA: "Error de permisos"
SOLUCIÓN:
• Ejecute el instalador como administrador
• Verifique que tenga permisos de escritura
