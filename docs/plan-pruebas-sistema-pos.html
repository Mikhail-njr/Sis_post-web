🔐 Autenticación y Seguridad

Login de Usuarios

Inicio de sesión válido Alta Verificar que un usuario registrado puede iniciar sesión con credenciales válidas
  1. Navegar a la página de login
  2. Ingresar nombre de usuario válido
  3. Ingresar contraseña correcta
  4. Hacer clic en "Iniciar Sesión"
Resultado esperado: El sistema redirige al dashboard y crea una sesión válida
Inicio de sesión con credenciales inválidas Alta Verificar que el sistema rechaza usuarios con credenciales incorrectas
  1. Navegar a la página de login
  2. Ingresar un usuario que no existe
  3. Ingresar una contraseña incorrecta
  4. Hacer clic en "Iniciar Sesión"
Resultado esperado: El sistema muestra mensaje de error "Credenciales inválidas"
Cierre de sesión Alta Verificar que el cierre de sesión invalida la sesión actual
  1. Iniciar sesión como usuario válido
  2. Hacer clic en "Cerrar Sesión"
  3. Intentar acceder a una ruta protegida
Resultado esperado: El sistema redirige al login y no permite acceso a rutas protegidas

Gestión de Credenciales

Cambio de contraseña Media Verificar que un usuario puede cambiar su contraseña
  1. Iniciar sesión como usuario
  2. Ir a configuración de cuenta
  3. Seleccionar "Cambiar Contraseña"
  4. Ingresar contraseña actual
  5. Ingresar nueva contraseña (mínimo 6 caracteres)
  6. Confirmar nueva contraseña
Resultado esperado: El sistema muestra mensaje de éxito y la nueva contraseña funciona
Protección de rutas Alta Verificar que las rutas protegidas requieren autenticación
  1. Cerrar sesión o usar navegador privado
  2. Intentar acceder directamente a /dashboard
  3. Intentar acceder directamente a /api/stats
Resultado esperado: El sistema redirige al login o retorna error 401

  1. Seleccionar un producto existente
  2. Modificar el precio o nombre
  3. Guardar cambios
Resultado esperado: Los cambios se reflejan inmediatamente en el listado
Eliminar producto Media Verificar que se puede eliminar un producto

Búsqueda por nombre Alta Verificar que la búsqueda por nombre funciona correctamente

CRUD de Clientes

Crear nuevo cliente Alta Verificar que se puede registrar un nuevo cliente
  1. Ir a gestión de clientes
  2. Hacer clic en "Nuevo Cliente"
  3. Completar: nombre, documento, teléfono, email, dirección
  4. Guardar cliente
Resultado esperado: El cliente se crea y aparece en el listado
Editar cliente Alta Verificar que se puede modificar información de un cliente
  1. Seleccionar un cliente
  2. Modificar algún campo (teléfono o dirección)
  3. Guardar cambios
Resultado esperado: Los cambios se reflejan en el listado y cuenta corriente
Eliminar cliente Media Verificar que se puede eliminar un cliente
  1. Seleccionar un cliente sin deudas
  2. Eliminar el cliente
Resultado esperado: El cliente se elimina (con validación de no tener deudas activas)

Cuenta Corriente

Ver cuenta corriente de cliente Alta Verificar que se muestran todas las deudas de un cliente
  1. Seleccionar un cliente
  2. Ir a "Cuenta Corriente"
Resultado esperado: Se muestran todas las deudas con productos, fechas y montos
Pago parcial de deuda Alta Verificar que se puede realizar un pago parcial de una deuda
  1. Seleccionar una deuda
  2. Registrar un pago menor al total
  3. Verificar que la deuda queda como pendiente
Resultado esperado: La deuda se actualiza con el monto pendiente correcto
Pago total de deuda Alta Verificar que se puede saldar completamente una deuda
  1. Seleccionar una deuda
  2. Registrar pago igual al monto total
  3. Verificar que la deuda se marca como pagada
Resultado esperado: La deuda se marca como pagada y ya no aparece como pendiente
Limpiar deudas de cliente Baja Verificar que un administrador puede limpiar todas las deudas de un cliente
  1. Iniciar sesión como administrador
  2. Seleccionar un cliente
  3. Usar la opción "Limpiar Deudas"
Resultado esperado: Todas las deudas del cliente se eliminan

💰 Gestión de Ventas

Ventas en Efectivo

Realizar venta en efectivo Alta Verificar el flujo completo de una venta en efectivo
  1. Escanear o buscar productos
  2. Agregar productos al carrito
  3. Seleccionar método de pago "Efectivo"
  4. Ingresar monto recibido
  5. Verificar cálculo de vuelto
  6. Confirmar venta
Resultado esperado: La venta se registra, el stock se descuenta y se genera ticket
Venta con tarjeta de débito/crédito Alta Verificar ventas con métodos de pago electrónicos
  1. Agregar productos al carrito
  2. Seleccionar método de pago "Tarjeta"
  3. Confirmar venta
Resultado esperado: La venta se registra correctamente con método de pago tarjeta

Ventas a Cuenta Corriente

Venta a cuenta corriente Alta Verificar que se puede registrar una venta a cuenta corriente de un cliente
  1. Buscar y seleccionar un cliente
  2. Agregar productos al carrito
  3. Seleccionar "Cuenta Corriente" como método de pago
  4. Confirmar venta
Resultado esperado: Se crea una deuda en la cuenta del cliente con los productos vendidos
Venta a cuenta corriente sin cliente Media Verificar que no se puede hacer venta a cuenta sin seleccionar cliente
  1. Agregar productos al carrito
  2. Seleccionar "Cuenta Corriente"
  3. No seleccionar ningún cliente
  4. Intentar confirmar
Resultado esperado: El sistema muestra error indicando que debe seleccionar un cliente

  3. Confirmar cancelación

Ver historial de ventas Alta Verificar que se puede ver el historial completo de ventas
  1. Ir a sección de ventas
  2. Verificar que aparecen todas las ventas
  3. Verificar filtros por fecha
Resultado esperado: Se muestra el listado de todas las ventas con detalles
